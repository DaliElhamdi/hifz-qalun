# حفظ قالون — Hifz Qalun

**حفظ القرآن الكريم برواية قالون عن نافع** — مجاني، دون إعلانات، دون حسابات.

- 🌐 **نسخة المتصفح:** https://dalielhamdi.github.io/hifz-qalun/
- 📱 **تطبيق أندرويد:** [تحميل أحدث إصدار (arm64-v8a، أغلب الهواتف)](https://github.com/DaliElhamdi/hifz-qalun/releases/latest/download/hifz-qalun-arm64-v8a.apk) ·
  [للهواتف القديمة (armeabi-v7a)](https://github.com/DaliElhamdi/hifz-qalun/releases/latest/download/hifz-qalun-armeabi-v7a.apk) ·
  [كل الإصدارات](https://github.com/DaliElhamdi/hifz-qalun/releases)

المصحف كاملًا بنص مجمع الملك فهد وخطّه لرواية قالون (يُتحقّق منه بالبصمة عند كل فتح)، سجل الحفظ
والمراجعة المتباعدة، المواضع الضعيفة، المتشابهات، الاختبارات، التفسير (الميسر، الجلالين، السعدي)
ومعاني الكلمات وأسباب النزول، ختمات التلاوة والعلامات. وفي تطبيق أندرويد: التلاوة بالميكروفون مع
كشف الأخطاء (دون إنترنت)، والتذكيرات.

**حفظ التقدّم:** في المتصفح تُحفظ بياناتك في المتصفح نفسه؛ صدّر نسخة احتياطية من «المزيد ← الإعدادات
← النسخ الاحتياطي»، وبالملف نفسه تنقل تقدّمك بين المتصفح وتطبيق أندرويد.

تثبيت التطبيق: افتح ملف APK على الهاتف واسمح بالتثبيت من هذا المصدر. الإصدارات الجديدة تُثبَّت فوق
القديمة دون أن تضيع البيانات.
