# دعاء ختم القرآن (#14)

`dua_khatm.json` is copied unchanged from a cited printed edition by `tool/dua/` once the owner has
approved the edition and the extracted text (never typed). Its SHA-256 is checked before it is shown
(`lib/ui/dua_khatm.dart`, `kDuaSha256`). Until then the app shows the page without the text.
